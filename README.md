# Академический архив Лилии Львовны Тимофеевой

Одностраничный сайт-портфолио на React, TypeScript и Vite. Он построен как расширяемый академический архив: данные вынесены в `src/data`, поэтому новые книги, публикации и проекты добавляются без изменения интерфейсных компонентов.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверка сборки

```bash
npm run build
```

## Страницы

- `index.html` — главная страница-портфолио.
- `publications.html` — полный список печатных работ (486 записей, 1997–2026)
  с фильтрами по диапазону лет, издательству, соавторам, темам и типу работы.

## Каталог публикаций и Google-таблица

Список печатных работ разобран на колонки из `Pechatnye_raboty.doc` и живёт в
Google-таблице, которую редактирует автор — сайт читает её при каждом открытии
страницы. Пошаговая инструкция: [ТАБЛИЦА-ПУБЛИКАЦИЙ.md](ТАБЛИЦА-ПУБЛИКАЦИЙ.md).

```bash
npm run sync:publications   # обновить встроенную резервную копию каталога из таблицы
npm run import:publications # заново разобрать Word-файл со списком печатных работ
```

Ссылка на опубликованный CSV таблицы задаётся в `src/config.ts`. Пока она пустая,
страница показывает встроенную копию `src/data/publicationsArchive.ts`.

## Данные и верификация

Первичная база создана по материалам, предоставленным заказчиком. Часть биографических деталей специально отмечена как требующая документальной проверки. Перед публичным расширением архива следует добавить постоянные ссылки на первоисточники, ISBN, полный список публикаций и разрешённые портретные фотографии.

## Публикация

В репозитории есть GitHub Actions workflow `.github/workflows/deploy.yml`. После первого push в `main` включите **Settings → Pages → Build and deployment → GitHub Actions**. Сайт будет доступен по адресу `https://<github-user>.github.io/timofeeva-academic/`.
