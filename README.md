# Академический архив Лилии Львовны Тимофеевой

Одностраничный сайт-портфолио на React, TypeScript и Vite. Он построен как расширяемый академический архив: данные вынесены в `src/data`, поэтому новые книги, публикации и проекты добавляются без изменения интерфейсных компонентов.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверка сборки

```bash
npm run build
```

## Данные и верификация

Первичная база создана по материалам, предоставленным заказчиком. Часть биографических деталей специально отмечена как требующая документальной проверки. Перед публичным расширением архива следует добавить постоянные ссылки на первоисточники, ISBN, полный список публикаций и разрешённые портретные фотографии.

## Публикация

В репозитории есть GitHub Actions workflow `.github/workflows/deploy.yml`. После первого push в `main` включите **Settings → Pages → Build and deployment → GitHub Actions**. Сайт будет доступен по адресу `https://<github-user>.github.io/timofeeva-academic/`.
