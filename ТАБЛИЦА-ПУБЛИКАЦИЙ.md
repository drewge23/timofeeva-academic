# Таблица публикаций: как ею пользоваться

Список печатных работ из файла `Pechatnye_raboty.doc` разобран на колонки —
**486 записей, 1997–2026**. Из него собраны:

| Файл | Что это |
| --- | --- |
| `public/publications.csv` | Таблица для загрузки в Google Таблицы |
| `public/publications.xlsx` | Та же таблица в формате Excel |
| `src/data/publicationsArchive.ts` | Встроенная копия каталога — сайт показывает её, если таблица недоступна |

Страница со списком и фильтрами — `publications.html`
(на сайте: **Печатные работы** в шапке и большая ссылка внизу раздела «Публикации»).

---

## Шаг 1. Завести Google-таблицу (делается один раз)

1. Откройте [Google Таблицы](https://sheets.google.com) под аккаунтом, к которому
   будет доступ у мамы, и создайте пустую таблицу.
2. **Файл → Импортировать → Загрузить** и выберите `public/publications.csv`.
3. В окне импорта: «Заменить текущий лист», разделитель — **запятая**,
   галочку «Преобразовывать текст в числа и даты» лучше **снять**
   (иначе Google испортит записи вида «№ 4 (100)»).
4. Переименуйте лист в **Публикации** и закрепите первую строку
   (*Вид → Закрепить → 1 строка*), чтобы шапка не уезжала.
5. Дайте маме доступ на редактирование: **Поделиться → добавить её почту → Редактор**.

## Шаг 2. Опубликовать таблицу как CSV

Сайт статический, поэтому он читает таблицу по прямой ссылке.

1. **Файл → Поделиться → Опубликовать в интернете**.
2. Слева выберите лист **Публикации**, справа формат
   **CSV (значения, разделённые запятыми)**.
3. Нажмите **Опубликовать** и скопируйте ссылку — она выглядит так:
   `https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?gid=0&single=true&output=csv`

> Публикуется только этот лист и только для чтения. Редактировать таблицу
> по-прежнему могут лишь те, кому вы дали доступ на шаге 1.

## Шаг 3. Вставить ссылку в сайт

Откройте `src/config.ts` и вставьте ссылку:

```ts
export const PUBLICATIONS_SHEET_CSV = 'https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?output=csv'
```

Закоммитьте изменение и запушьте в `main` — GitHub Actions пересоберёт сайт.
После этого **страница публикаций читает таблицу при каждом открытии**:
мама меняет строку в Google Таблицах, обновляет страницу сайта — правка уже там,
пересобирать сайт не нужно.

Google отдаёт опубликованный CSV с задержкой примерно до пяти минут — это нормально.

## Как мама добавляет публикацию

Открыть таблицу, добавить строку (удобнее сверху, но порядок строк не важен —
сайт всё равно сортирует по годам) и заполнить колонки:

| Колонка | Что писать | Обязательно |
| --- | --- | --- |
| **Год** | Только четыре цифры: `2026` | да |
| **Тип** | `Статья в журнале`, `Статья в сборнике`, `Книга`, `Методическое пособие`, `Монография`, `Рабочая тетрадь`, `Программа / планирование`, `Диссертация` | да |
| **Название** | Название работы без авторов и выходных данных | да |
| **Соавторы** | Через точку с запятой: `Бережнова О.В.; Гафнер В.В.` Себя указывать не нужно | нет |
| **Издательство** | Только издательство: `Просвещение`, `Детство-Пресс`. У статей в журналах его обычно нет — оставляйте пустым, название журнала останется в «Полном описании» | если есть |
| **Темы** | Одна-две через точку с запятой, лучше из уже используемых: `Культура безопасности; Дошкольное образование` | желательно |
| **Страницы** | `с. 24–30` | нет |
| **DOI**, **EDN** | Идентификаторы, если есть | нет |
| **Ссылка** | Адрес публикации в интернете — название станет кликабельным | нет |
| **Полное описание** | Библиографическая запись целиком, как в списке печатных работ | да |

Фильтр по годам работает диапазоном: «с 2020 по 2022», можно задать только начало
(«с 2020») или только конец («по 2025»).

Важно, что фильтры на сайте собираются из самих значений: если в одной строке
написать «Просвещение», а в другой «Изд-во Просвещение», в списке появятся
два разных издательства. Проще выбирать значение из соседней строки
(в Google Таблицах — начать печатать, он подскажет) или скопировать ячейку.

Колонки можно менять местами и даже переименовывать — сайт ищет их по заголовку
(понимает и `Издательство`, и `Издатель`). Нельзя только удалять
строку заголовков и колонку **Название**.

## Обслуживание

**Обновить резервную копию каталога** (чтобы сайт корректно работал, даже если
Google недоступен, и чтобы изменения были видны в истории git):

```bash
npm run sync:publications
```

**Пересобрать таблицу из Word заново** — если появится новая версия
`Pechatnye_raboty.doc`. Внимание: команда перезапишет `public/publications.csv`,
поэтому запускать её после заведения Google-таблицы нужно только осознанно.

```bash
npm run import:publications
```

## Если что-то пошло не так

- **Сайт пишет «Показана сохранённая копия каталога»** — ссылка в `src/config.ts`
  пустая. Вернитесь к шагу 3.
- **«Таблица сейчас недоступна»** — публикация в интернете отключена или ссылка
  ведёт не на CSV. Проверьте, что в конце ссылки есть `output=csv`.
- **Публикация не появилась** — проверьте, что заполнены «Название» и «Год»,
  и подождите несколько минут: Google обновляет опубликованный файл не мгновенно.
- **Строка пропала со страницы** — скорее всего, пустая колонка «Название».
